# Agent Decoder

หน้าเว็บส่งคำตอบสำหรับกิจกรรม "ภารกิจซองลับ Agent ถอดรหัส"

ทีมพิมพ์ **Agent Code** (รหัส Agent หน้าซอง) และ **Secret Code** (ประโยคลับ) แล้วกด ถอดรหัส
ถ้าตรงกันจะขึ้น "ถูกต้อง" ถ้าไม่ตรงจะขึ้น "ไม่ถูกต้อง" (เว้นวรรคหรือไม่เว้นก็ได้ ตัวพิมพ์เล็ก/ใหญ่ของรหัสไม่มีผล)

คำตอบเก็บเป็นค่า SHA-256 เท่านั้น นักเรียนเปิดดู source ก็ไม่เห็นประโยคลับ
